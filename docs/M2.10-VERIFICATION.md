# M2.10 — Persistent inventory dashboard verification

## Implemented

- Default dense table, column sorting (numeric-aware version keys), combined search,
  lifecycle/technology/remote filters and 50-row pages. Detail contains rescan,
  short notes, text todo-list, technologies, dated remotes/dependency comparisons
  and Markdown links. Earlier worksheets remain secondary links.
- Flyway V5: configured roots, last observations and lifecycle/notes/tasks in H2.
  Startup/30-minute/manual jobs, one worker, no overlapping jobs, explicit import
  confirmation for new projects. Snapshot writes check identity/path/update date
  so a concurrent move away and back cannot accept an obsolete scan.
- One Git repository by default, nested independent repositories remain distinct;
  non-Git Maven/Python and Node manifests supported. Bounded module declarations,
  Angular/Bootstrap constraints and partial physical source line counts.
- Automatic dated Git remote advertisement checks, local working-tree evidence,
  no fetch/index refresh/project writes. Public registry dependency comparison on
  demand, bounded response bodies/timeouts and no Maven/plugin execution.
- Short notes/tasks/lifecycle included in the current private JSON metadata backup.
  Roots and observations stay in local H2; reconfigure/rescan after JSON-only restore.

## Explicit limits / pending acceptance

- Browser rendering was not verified: Playwright Chromium/headless-shell download
  failed with a truncated/invalid ZIP. HTML/HTTP behavior is tested, not visual QA.
  Owner desktop/narrow-screen review remains necessary before M3.
- Maven effective model, parent/profile/property resolution, transitives, lockfile
  resolution, Java EOL/vendor support and vulnerability/Sonar analysis are absent.
  A differing release is a comparison to examine, never a debt/security verdict.
- Network/error classes are best-effort Git diagnostics, not guaranteed raw HTTP
  codes. Missing/private stays ambiguous. Git credentials/known_hosts must already
  work noninteractively; indirect/shallow/complex layouts remain unsupported.
- Inventory bounds and filesystem stable-tree assumptions remain documented in
  README/ADR-021. No large-portfolio benchmark or actual server outage induced.
- The dashboard reads persisted data; reload after an asynchronous job to display
  its latest results. Simple tasks are text lines, not a workflow/task manager.
- Roots and rebuildable observations are excluded from portable JSON; full H2
  persistence is verified. No arbitrary project file edits or builds are executed.

GitHub Ubuntu/Windows exact-head CI outcomes are recorded in the pull request.
Do not infer Windows success from these local Linux results. M3 remains paused.
