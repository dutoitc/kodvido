# M2.9 — Default port and filterable catalogue

## Implemented

Default loopback port 8930. Responsive table with names/paths, bounded declared
version evidence, script counts, file activity, HEAD commit date, restart completeness,
unknown/failed backup counts and last interaction. Search, technology/state filters,
three sort orders, empty states and 25-row pagination run in the engine without
filesystem detection. Explicit inspection retains at most 1000 bounded summaries;
restart, successful relocation/removal and identity mismatch invalidate them.
No new dependencies, schema migration or JSON-format change. Source files untouched.

PR #9 had been merged into feature/m2-backup-evidence after PR #8 reached main. Its
reviewed changes are included in this branch so that they reach main as intended.

## Limits

Summaries are transient and may be stale. At most four version evidence entries,
160 characters per field; open an explicit inspection for fuller evidence. Technology
filters mean declarations found, not exhaustive Maven/Python classification. Counts
from incomplete inspections cannot establish inactivity. Backup claims are manual.
The projection reads catalogue metadata per row before paging; very large catalogues
have not been benchmarked. No bulk scanning, background jobs or M3 export is added.
