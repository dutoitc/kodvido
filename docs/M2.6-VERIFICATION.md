# M2.6 verification — bounded local interactions

## Implemented

Separate persisted local-interaction evidence for R08: inspection requests,
successful workflow saves and relocations. Display the latest recorded event and
up to 100 events on the project page, distinct from Git/file activity. Empty history
is UNKNOWN. Read-only page/document views, imports and older actions do not create
invented events. An inspection request does not claim success.

Flyway V3 adds a small FK-linked table and project/sequence index. Parent locking
serializes insertion and retention. Successful notes/path mutations and their events
commit atomically; failure rolls back both. Relocation retains history; catalogue
removal cascades only metadata. Event data is fixed kind, project UUID, local-clock
time and sequence, without paths, content, commands or user identities.
