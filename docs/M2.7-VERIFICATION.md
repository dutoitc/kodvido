## Limits and remaining work

This is a declaration workflow, not backup software or automatic verification.
No remote fetch/push, copy, database backup or restore is performed. Old dates have
no automatic expiry policy; no new interaction-event kind is added. JSON files are
private metadata, not sanitized reports, and older application versions cannot
import v2. The known intermittent Windows H2 reopen failure has not been proven
fixed; monitor CI and retain sanitized SQL diagnostics if it recurs.

Remaining M2: suggestion cards, sanitized local detector-gap issue drafts and final
acceptance/documentation review. Richer stack detection remains bounded/partial.
M3 HTML/PDF exports have not started.
